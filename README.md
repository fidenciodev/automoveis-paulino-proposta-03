# Paulino Automóveis — Proposta 03

**[Visualizar a proposta online](https://fidenciodev.github.io/automoveis-paulino-proposta-03/)**

Proposta de apresentação do site da Paulino Automóveis, feita com HTML, CSS e JavaScript. Inclui abertura visual da proposta 02, carrossel automático a cada 6 segundos, layout responsivo, filtros de veículos e detalhes demonstrativos. Os textos de descrição e apoio foram ampliados para melhorar a leitura.

## Como visualizar

Abra a pasta do projeto no VS Code e use **Open with Live Server** no arquivo `index.html`.

Outra opção, com Python instalado:

```sh
python -m http.server 5500
```

Acesse `http://localhost:5500` no navegador. Não é necessário instalar Node.js ou dependências.

## Arquivos

- `index.html`: página principal.
- `style.css` e `hero.css`: estilos e abertura.
- `app.js` e `carousel.js`: interações e carrossel.
- `cars.json`: dados da vitrine.
- `assets/`: logo e imagens.

## Sobre a demonstração

Este projeto é uma demonstração de front-end. Os formulários e interações de contato não enviam solicitações reais. Os veículos e preços representam uma captura do estoque e precisam ser confirmados com a loja.

Logo e fotos foram obtidas no site da Paulino Automóveis e usadas para apresentar esta proposta.
